Sobre o projeto

O SGV é uma aplicação web desenvolvida para auxiliar empresas no controle de vendas, cálculo de lucros e análise de desempenho comercial. O sistema permite cadastrar produtos, registrar vendas, visualizar relatórios gráficos e comparar resultados entre meses consecutivos.
